
## Quality Alert System

The WSA now includes a fully configurable Quality Alert System. This allows administrators to set up conditional rules to detect specific defects, threshold breaches, and missing data points directly from the live Particle Summary Excel feed.

### Features:
- **Rule Engine:** Support for complex AND/OR logic over various defect parameters.
- **Deduplication & Cooldowns:** Built-in anti-spam measures to prevent alert fatigue.
- **Admin Dashboard:** Manage rules and view recent alerts through the web UI.
- **Power Automate Integration:** Seamless integration for sending HTML Outlook emails via Microsoft Power Automate.

For instructions on configuring the Power Automate flows, please refer to [POWER_AUTOMATE_INTEGRATION.md](POWER_AUTOMATE_INTEGRATION.md).
